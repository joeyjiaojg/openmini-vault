# openmini-vault · 小盒子私有市场的密文镜像

这里只有**密文**，没有任何可读内容、没有密钥、没有口令。

| 文件 | 说明 |
|---|---|
| `meta.json` | 公开参数：catalog 文件名 + 每个账号一条密钥信封（盐、迭代次数、被加密的主密钥） |
| `catalog.enc` | 加密的应用清单 |
| `apps/<hash>.enc` | 加密的应用包 |

- 加密：AES-256-GCM 逐文件，12 字节 nonce，AAD 绑定文件路径；文件头 `OMV1`
- 密钥：每个账号用自己的口令 + 自己的盐 PBKDF2 派生出 KEK，用它解开 `meta.json` 里的信封得到主密钥
- 文件名是 `sha256(vid + 应用 id)` 的前 16 位，无法从文件名看出内容

没有账号口令，这里的字节与随机数据没有区别。使用方式见小盒子宿主的「私有市场」Tab。
